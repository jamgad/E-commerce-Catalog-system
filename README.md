A Java Swing-based e-commerce application with customer and administrator interfaces.
Features
Browse, search, and filter products
Add, update, and remove shopping cart items
Checkout with 14% tax calculation
Generate and print final bills
Add, edit, and remove products as an administrator
Manage product stock
Save products and receipts using text files
Input validation and custom exception handling
Technologies
Java
Java Swing
OOP
File I/O
ArrayList
Exception Handling
How to Run
Compile and run the main file:
javac ECommerceCatalogSystem.java
java ECommerceCatalogSystem

Project Purpose
This project demonstrates the use of Java OOP, GUI development, event handling, file handling, and exception handling in a simple e-commerce system.
